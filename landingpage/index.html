Soluciones

Dos versiones, una misma misión de servicio.

PY
Versión escritorio

Python + interfaz local

Diseñada para trabajo directo y operativo, con captura segura de datos personales y validación local para respaldar el proceso de levantamiento del censo.

  • Registro guiado de información
  • Validación de campos y consistencia
  • Persistencia local con SQLite
  • Uso orientado a equipos campo
WEB
Versión web

Acceso remoto y digital

Pensada para compartir información y mejorar la colaboración entre áreas, con una experiencia moderna que facilita la consulta, gestión y visualización de datos.

  • Interfaz responsive y moderna
  • Acceso desde navegador
  • Gestión centralizada de datos
  • Paneles y flujos de trabajo ágiles

Instalación

Guía rápida para instalar cada versión del programa.

Versión escritorio

Python

  1. Descarga la versión disponible desde el repositorio oficial.
  2. Abre la terminal dentro de la carpeta del proyecto.
  3. Instala las dependencias con:
    pip install -r requirements.txt
  4. Ejecuta la aplicación con:
    python main.py
Versión web

Aplicación en navegador

  1. Clona el repositorio de GitHub del proyecto.
  2. Accede a la carpeta raíz del proyecto.
  3. Instala las dependencias con:
    npm install
  4. Inicia el entorno local con:
    npm run dev
